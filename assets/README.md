# Fondos y marca de Ascendra

Esta es la carpeta operativa para las imágenes que usa el dashboard. Cambia el
archivo conservando exactamente su nombre y formato, y la aplicación tomará la
nueva versión sin modificar código.

| Archivo | Uso |
| --- | --- |
| `leaves-day.jpg` | Fondo principal en modo claro. |
| `galaxy.jpg` | Fondo principal en modo oscuro. |
| `login.jpg` | Fondo de la pantalla de acceso. |
| `xolo-wolf.png` | Logotipo del encabezado. |

Para ver el cambio localmente, sustituye el archivo y recarga el navegador.
Para Render, confirma el cambio de imagen en GitHub y realiza un despliegue.
Las imágenes no contienen datos operativos y sí se publican con el código.
